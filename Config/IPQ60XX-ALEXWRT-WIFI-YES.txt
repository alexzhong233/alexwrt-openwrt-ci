# NSS 无线加速由上游的 nss-wifi-drv 提供：它自己 boot NSS 固件，用 wifili 把
# 无线帧直接送进 NSS 硬件。实测 /sys/bus/platform/devices/39000000.nss/state 里
#   ready=1  peers=5  wlan=3  rings_ready=1
# wlan=3 是位掩码 1|2，表示内置 AHB 和外挂 PCIe 卡两路都已卸载。
#
# CONFIG_ATH11K_NSS_WIFI 必须为 y：它决定 /usr/share/nss-wifi/wlan 的内容是 1，
# 少了这行，启动脚本会认为本机没有可卸载的 WiFi，直接退回 host path。
#
# 固件线不在这里钉版本：上游 nss-firmware 的 choice 默认就是 12.5
# （`default NSS_FIRMWARE_VERSION_12_5`，另有 `NSS_LINE:=$(if ...11_4,11.4,12.5)`），
# 显式写死只会挡住上游将来改默认，所以跟着上游走。两条线唯一的差别是 802.11s：
# 12.5 不接受 802.11s mesh 接口，11_4 是最后一条支持的线；要跑 802.11s 再手动选。
CONFIG_PACKAGE_nss-firmware=y
CONFIG_PACKAGE_kmod-nss-wifi-drv=y
CONFIG_ATH11K_NSS_WIFI=y
# 自建的 NSS 状态页：读 nss-wifi-drv 的 debugfs（wifili_rx / flows / log），
